Verbo to go: presente, pasado y usos cotidianos

El verbo to go significa “ir” y además es uno de los más usados del inglés, tanto en contextos formales como en la conversación diaria o informal. Se emplea para hablar de desplazamientos y actividades frecuentes: go home (ir a casa), go out (salir), go shopping (ir de compras), go to bed (acostarse) o go on (continuar). En presente toma la forma goes con he / she / it, y su pasado irregular es went. En esta guía verás sus usos clave, estructuras comunes, phrasal verbs, ejemplos y práctica para su aprendizaje.

Usos principales

  • Movimiento / destino: go to school, go to work, go home.
  • Actividades y planes: go shopping, go running, go out.
  • Eventos / viajes: go to a concert, go abroad, go camping.
  • Procesos / estados: go bad (echarse a perder), go crazy (volverse loco).
  • Expresiones con “on”: go on (continuar), go on vacation (irse de vacaciones).

Estructuras comunes

  • go + lugar: I go to school → voy a la escuela.
  • go + verbo-ing (actividad): We go swimming → vamos a nadar.
  • go + for: Let’s go for a walk → vamos a dar un paseo.
  • go + with: Who will go with you? → ¿Quién irá contigo?
  • go + on: Go on, please → continúa, por favor.

Phrasal verbs frecuentes con go

  • go out: salir
  • go in / go into: entrar
  • go back: regresar
  • go on: continuar / suceder
  • go over: repasar / revisar
  • go off: sonar / explotar / apagarse
  • go along (with): estar de acuerdo / acompañar
  • go by: pasar (el tiempo)
  • go through: atravesar / experimentar
  • go ahead: seguir adelante

Ejemplos en contexto

  • “We go to school every day.”

    Vamos a la escuela todos los días.

  • “She went to Paris last summer.”

    Ella fue a París el verano pasado.

  • “Let’s go out tonight.”

    Salgamos esta noche.

  • “What’s going on?”

    ¿Qué está pasando?

  • “Time goes by so fast.”

    El tiempo pasa muy rápido.

Práctica rápida

  1. Complete (presente): “I ____ to the gym every morning.”
  2. Complete (pasado): “They ____ to Spain last year.”
  3. Negación (presente): “He ____ not go to work on Sundays.”
  4. Pregunta (presente): “Where ____ you ____ after class?”
  5. Phrasal: “Let’s ____ ____ tonight.” (salir)
  6. Expresión: “What’s ____ ____?” (¿qué pasa?)
  7. Vocabulario: “Don’t ____ crazy!” (¡no te vuelvas loco!)
  8. Colocación: “We ____ for a walk every evening.”
  9. Tiempo verbal: “The alarm ____ off suddenly.”
  10. Traducción: “Ella fue al cine.” → “She ____ to the cinema.”
